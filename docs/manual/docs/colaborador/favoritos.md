# Favoritos

**Favoritos** é a sua lista pessoal de atalhos: as pastas e os arquivos que
você usa com frequência, reunidos num lugar só, para chegar a eles sem
percorrer as pastas.

## Marcar e desmarcar

Em **Documentos**, cada pasta e cada arquivo tem a ação **Favoritar**. Ao
marcar, aparece uma estrela ao lado do nome e a ação passa a se chamar
**Remover dos favoritos**.

- Você só consegue marcar o que já pode abrir.
- Os seus favoritos são só seus: ninguém mais vê a sua lista, nem a
  administração da unidade.
- Cada pessoa pode ter até **200** favoritos. Ao atingir o limite, o sistema
  avisa — remova algum para marcar outro.

## A lista

Abra **Favoritos** no menu, entre **Recentes** e **Compartilhados comigo**. A
lista mostra, do marcado mais recentemente para o mais antigo:

| Coluna         | O que mostra                                                        |
| -------------- | ------------------------------------------------------------------- |
| **Tipo**       | Se é pasta ou arquivo.                                              |
| **Nome**       | Clique para abrir: a pasta abre em Documentos, o arquivo no visualizador. |
| **Onde está**  | A pasta que contém o item, ou "Raiz da unidade".                    |
| **Marcado em** | O dia em que você marcou.                                           |
| **Ações**      | Abrir ou visualizar, **Baixar** (quando você pode baixar) e **Remover dos favoritos**. |

!!! note "Favorito não é permissão"
    Marcar um favorito não dá acesso a nada. Se você deixar de ter acesso a um
    item — uma permissão temporária que venceu, um documento declarado
    obsoleto, um arquivo que foi para a lixeira —, ele simplesmente some da
    lista, sem aviso de erro. Se o acesso voltar (ou o item for restaurado da
    lixeira), ele volta a aparecer, sem precisar marcar de novo. Quando um item
    é excluído definitivamente da lixeira, a marca é apagada.

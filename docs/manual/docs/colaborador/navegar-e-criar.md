# Navegar pelos arquivos e criar pastas

## Navegar

Abra **Documentos** no menu. Você vê suas pastas e arquivos em formato de lista, no
estilo "explorador de arquivos". Clique em uma pasta para entrar nela; use a **trilha
de navegação** (breadcrumb) no topo para voltar a qualquer nível anterior com um
clique.

Você só vê os itens que **criou** ou que lhe foram **liberados**. Se uma pasta contém
itens sem permissão para você, eles simplesmente não aparecem.

### Quando a pasta não tem nada a mostrar

Se a pasta não tem nenhum item visível para você, a lista dá lugar a um aviso de que
**ainda não há documentos ali**. Quando você tem permissão para enviar naquela pasta, o
aviso traz também o botão **Enviar documento**, que leva direto à área de envio. Sem
essa permissão, o aviso aparece sozinho — a ação de enviar não é oferecida, porque o
sistema não ofereceria uma ação que recusaria em seguida.

## Criar pastas

Dentro de **Documentos**, clique em **Nova pasta**, dê um nome e confirme. A pasta é
criada no local onde você está.

!!! note "Renomear e mover pastas não existem nesta versão"
    Pastas não podem ser renomeadas nem movidas. Se precisar mudar o nome de uma
    pasta, crie uma nova e mova o conteúdo reenviando-o. Ver
    [Renomear e excluir](renomear-e-excluir.md).
